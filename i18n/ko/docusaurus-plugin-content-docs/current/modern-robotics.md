# Modern Robotics

강체 변환과 screw theory부터 Jacobian, 역기구학, 동역학, 모션 플래닝까지 로봇 운동을 다루는 기술 노트 시리즈입니다. 수학적 기초를 브라우저에서 실행되는 구현과 연결합니다.

같은 개념을 C++로 구현해, 브라우저에서 기구학, 플래닝, 동역학을 직접 확인할 수 있습니다.

## 이 시리즈를 읽는 방법

- **강체 운동과 screw theory**에서 로봇 운동을 설명하는 기하학적 언어를 만듭니다.
- **좌표계와 Lie group**에서 좌표 표현과 Product of Exponentials의 관계를 설명합니다.
- **Jacobian과 역기구학**에서 속도 매핑과 목표 자세 계산을 다룹니다.
- **동역학과 모션 플래닝**에서 모델을 실행 가능한 궤적과 제어로 확장합니다.
- **실행 가능한 구현**에서 브라우저를 통해 이론을 직접 확인합니다.
