# Modern Robotics

Modern Robotics 노트 시리즈의 시작점입니다.

글은 블로그 형식으로 발행하며, 이 사이드바는 각 글에서 다루는 개념의 흐름을 정리합니다.

## 이 시리즈를 읽는 방법

Part 1부터 Part 6B 순서로 읽는 것을 권장합니다.

- **Foundations**는 강체 변환, twist, screw axis, Lie group의 언어를 다룹니다.
- **Kinematics and Control**은 Jacobian, manipulability, 역기구학을 다룹니다.
- **Dynamics and Planning**은 궤적, 제어, 모션 플래닝까지 확장합니다.
