# Optimal Parking

Optimal Parking은 기하학적 경로 플래닝과 수치 궤적 최적화를 연결하는 자율주차 시스템입니다. RRT*로 초기 경로를 만들고, 차량 모델과 입력 범위, 장애물 안전 여유를 지키는 일련의 QP를 통해 경로를 개선합니다.

같은 C++ 플래너를 네이티브 라이브러리로 빌드하거나 WebAssembly로 컴파일해 브라우저 데모에서 실행할 수 있습니다.

## 이 시리즈를 읽는 방법

챕터는 플래너의 데이터 흐름을 따라 구성되어 있습니다.

- **차량 모델과 문제 정의**에서 상태, 입력, 주차 목표를 정의합니다.
- **RRT* 초기화**에서 충돌 없는 기하학적 경로를 찾습니다.
- **최적제어**에서 실행 가능한 궤적의 목적 함수, 동역학, 제약 조건을 정의합니다.
- **궤적 최적화**에서 초기 경로를 부드럽고 실행 가능한 궤적으로 개선합니다.
- **제약 조건과 튜닝**에서 장애물 회피, 범위, 패널티, 수렴을 설명합니다.
- **구현과 WebAssembly**에서 C++ 솔버를 인터랙티브 데모와 연결합니다.
- **시리즈 요약**에서 전체 플래닝 흐름을 하나의 구조로 정리합니다.
