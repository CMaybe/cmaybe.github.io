# 사족 보행을 위한 Convex MPC

Convex MPC는 강체 동역학과 접지 제약부터 최적 지면 반력 계획과 실시간 보행 제어까지, 사족 로봇의 동적 보행을 정리한 기술 노트 시리즈입니다.

고정 타이밍 보행에 걸쳐 지면 반력을 계획하면서 유한 수평선 추종 비용을 최소화하는 컨벡스 공식화를 전개합니다. 같은 이론을 MuJoCo에서 ANYmal C 로봇에 적용하고, C++ 구현을 WebAssembly로 컴파일해 브라우저에서 시각화할 수 있습니다.

## 이 시리즈를 읽는 방법

- **강체 동역학:** 네 개의 점 접지를 가진 사족 로봇의 운동 방정식을 설정합니다.
- **단일 강체 모델:** 동역학을 13-상태 모델로 단순화하고 선형화와 이산화를 유도합니다.
- **MPC 공식화:** 궤적 추종 문제를 40 Hz에서 풀이하는 응축된 이차계획법(QP)으로 변환합니다.
- **보행 및 유상 제어:** 고정 타이밍 보행과 힘 계획의 관계, 독립적인 유상 다리 궤적을 설명합니다.
- **실용적 구현:** 솔버 시간, 수치 조건화, 파라미터 튜닝, 배포 선택을 논의합니다.
- **시리즈 요약:** 사족 제어 루프 전체를 하나의 구조로 정리합니다.
