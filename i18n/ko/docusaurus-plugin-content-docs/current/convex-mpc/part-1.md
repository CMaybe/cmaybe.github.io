# 강체 동역학

## 모델

사족 로봇은 질량 $m$과 관성 텐서 $I$를 가진 단일 강체로 모델링되며, 네 개의 점 접지로 지지됩니다. 몸의 상태는 다음으로 구성됩니다:

- 위치: $\mathbf{p} \in \mathbb{R}^3$ (월드 프레임의 무게중심)
- 방향: $\mathbf{R} \in SO(3)$ (회전 행렬, 또는 오일러 각 $\Theta$)
- 선속도: $\dot{\mathbf{p}} \in \mathbb{R}^3$
- 각속도: $\boldsymbol{\omega} \in \mathbb{R}^3$

## 운동 방정식

중력과 접지 힘을 받는 강체의 Newton-Euler 방정식:

$$\mathbf{a} = \ddot{\mathbf{p}} = \mathbf{g} + \frac{1}{m} \sum_{i=1}^{4} \mathbf{f}_i$$

$$\dot{\boldsymbol{\omega}} = I^{-1} \left( \sum_{i=1}^{4} (\mathbf{r}_i - \mathbf{p}) \times \mathbf{f}_i - \boldsymbol{\omega} \times I \boldsymbol{\omega} \right)$$

여기서:
- $\mathbf{g} = [0, 0, -g]^\top$ 중력 가속도
- $\mathbf{f}_i \in \mathbb{R}^3$ 발 $i$의 지면 반력
- $\mathbf{r}_i \in \mathbb{R}^3$ 월드 프레임의 발 위치
- 외적 연산자 $\times$ 회전 동역학 표현

## 접지 제약

발 $i$가 지면과 접지한 경우 (지지 단계):

1. **기구학 제약:** 발의 관통 없음
   $$z_i \geq 0$$

2. **마찰 원뿔:** 쿨롱 마찰 만족
   $$\|\mathbf{f}_{i,xy}\| \leq \mu f_{i,z}$$
   여기서 $\mu$는 마찰 계수, $\mathbf{f}_{i,xy}$는 수평 성분입니다.

3. **음이 아닌 수직력:**
   $$f_{i,z} \geq 0$$

발 $i$가 유상인 경우 (접지 없음):
$$\mathbf{f}_i = \mathbf{0}$$

## 단순화: 단일 강체 모델

단일 강체(SRB) 모델은 다음을 가정합니다:

1. **조인트 컴플라이언스 없음:** 다리는 완전히 경직됨 (실제로는 딱딱한 액추에이터로 만족)
2. **즉각적 힘 전달:** 접지 힘이 몸으로 즉시 전파됨
3. **모든 다리가 단일 점 지지:** 몸의 공간 범위를 무시
4. **고정 접지 일정:** 지지/유상 전환이 정해진 시간에 발생 (보행 일정에서 다룸)

이 근사가 효과적인 이유:

- 다리 질량이 작음 (일반적으로 다리당 본 체중의 10-15%)
- 다리 강성이 지배적이어서 컴플라이언스 오류 무시할 수 있음
- 접지 힘이 다리 관성보다 동역학을 지배

## 참조 동역학

MPC는 위치 및 방향에 대한 참조 궤적을 추종합니다. 정의합니다:

- 참조 속도: $\dot{\mathbf{p}}^{\text{ref}}_k$ (명령됨, 포화됨)
- 참조 위치: $\mathbf{p}^{\text{ref}}_k = \int_0^k \dot{\mathbf{p}}^{\text{ref}}_i dt$ (적분된 참조)
- 참조 방향: $\Theta^{\text{ref}}_k$ ($\omega^{\text{ref}}_z$에서)
- 참조 몸 높이: $p^{\text{ref}}_{z,k}$ (고정 또는 변조됨)

컨트롤러는 다음을 최소화하는 지면 반력 $\{\mathbf{f}_i\}$를 풉니다:

$$J = \sum_{k=0}^{N-1} \left( \|\mathbf{x}_k - \mathbf{x}^{\text{ref}}_k\|_Q^2 + \|\mathbf{u}_k\|_R^2 \right)$$

제약:
- 각 타임스텝의 선형화된 동역학
- 마찰 원뿔 및 힘 범위
- 고정 타이밍 보행의 접지 일정 제약

## 왜 이것이 작동하는가

핵심 통찰은 **지면 반력이 결정 변수**라는 것입니다. 조인트 토크가 아닙니다:

- 직접성: 세상이 제약하는 것을 직접 최적화 (접지 힘)
- 볼록성: 마찰 원뿔은 볼록 집합; 힘 추종 비용은 이차식
- 실시간성: 결과 QP는 40 Hz에서 5ms 내에 풀이 가능할 정도로 작음
- 견고성: 다리 동역학의 명시적 모델링 불필요 (복잡하고 로봇-특정적)
