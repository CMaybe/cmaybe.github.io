단일 강체 모델

상태 표현​

MPC 상태는 13차원입니다:

x=[Θ,p,ω,p˙]∈R13\mathbf{x} = [\Theta, \mathbf{p}, \boldsymbol{\omega}, \dot{\mathbf{p}}] \in \mathbb{R}^{13}x=[Θ,p,ω,p˙​]∈R13

분해하면:

  • Θ=[θz,θy,θx]\Theta = [\theta_z, \theta_y, \theta_x]Θ=[θz​,θy​,θx​] — ZYX 오일러 각 (몸 방향)
  • p=[px,py,pz]\mathbf{p} = [p_x, p_y, p_z]p=[px​,py​,pz​] — 무게중심 위치 (월드 프레임)
  • ω=[ωx,ωy,ωz]\boldsymbol{\omega} = [\omega_x, \omega_y, \omega_z]ω=[ωx​,ωy​,ωz​] — 각속도 (몸 프레임)
  • p˙=[p˙x,p˙y,p˙z]\dot{\mathbf{p}} = [\dot{p}_x, \dot{p}_y, \dot{p}_z]p˙​=[p˙​x​,p˙​y​,p˙​z​] — 선속도 (월드 프레임)

연속 시간 상태-공간 형식​

강체 방정식을 비선형 동역학 시스템으로 작성:

x˙=f(x,u)\dot{\mathbf{x}} = \mathbf{f}(\mathbf{x}, \mathbf{u})x˙=f(x,u)

제어 입력은 지면 반력의 벡터:

u=[f1,f2,f3,f4]⊤∈R12\mathbf{u} = [\mathbf{f}_1, \mathbf{f}_2, \mathbf{f}_3, \mathbf{f}_4]^\top \in \mathbb{R}^{12}u=[f1​,f2​,f3​,f4​]⊤∈R12

연속 동역학:

Θ˙=T(Θ)ω\dot{\Theta} = \mathbf{T}(\Theta) \boldsymbol{\omega}Θ˙=T(Θ)ω

p˙=v\dot{\mathbf{p}} = \mathbf{v}p˙​=v

v˙=g+1m∑i=14fi\dot{\mathbf{v}} = \mathbf{g} + \frac{1}{m} \sum_{i=1}^{4} \mathbf{f}_iv˙=g+m1​∑i=14​fi​

ω˙=I−1(∑i=14(ri−p)×fi−ω×Iω)\dot{\boldsymbol{\omega}} = I^{-1} \left( \sum_{i=1}^{4} (\mathbf{r}_i - \mathbf{p}) \times \mathbf{f}_i - \boldsymbol{\omega} \times I \boldsymbol{\omega} \right)ω˙=I−1(∑i=14​(ri​−p)×fi​−ω×Iω)

여기서 T(Θ)\mathbf{T}(\Theta)T(Θ)는 방향 기구학 행렬입니다.

평형점 근처에서의 선형화​

MPC의 경우 참조 궤적 근처에서 선형화합니다. 호버링 평형점(속도 제로, 수평 방향) 근처:

xk+1=Axk+Buk+c\mathbf{x}_{k+1} = \mathbf{A} \mathbf{x}_k + \mathbf{B} \mathbf{u}_k + \mathbf{c}xk+1​=Axk​+Buk​+c

야코비안:

A=∂f∂x∣ref,B=∂f∂u∣ref\mathbf{A} = \frac{\partial \mathbf{f}}{\partial \mathbf{x}} \bigg|_{\text{ref}}, \quad \mathbf{B} = \frac{\partial \mathbf{f}}{\partial \mathbf{u}} \bigg|_{\text{ref}}A=∂x∂f​​ref​,B=∂u∂f​​ref​

핵심 통찰:

  • A\mathbf{A}A는 방향 기구학, 중력 결합, 자이로스코픽 항을 포함
  • B\mathbf{B}B는 각 접지 힘이 몸 가속도와 회전에 영향을 미치는 방식 인코딩
  • 선형화는 작은 편차(트로트 속도)에 유효하고, 고속 플립에는 유효하지 않음

이산화: 영순서 유지​

MPC는 40 Hz(25ms 타임스텝)에서 실행됩니다. 각 간격 동안 힘이 일정하다고 가정:

xk+1=∫tktk+1f(x(t),uk) dt\mathbf{x}_{k+1} = \int_{t_k}^{t_{k+1}} \mathbf{f}(\mathbf{x}(t), \mathbf{u}_k) \, dtxk+1​=∫tk​tk+1​​f(x(t),uk​)dt

선형 시스템의 경우:

xk+1=(I+AΔt+(AΔt)22+…)xk+(BΔt+AB(Δt)22+…)uk+c\mathbf{x}_{k+1} = \left( I + \mathbf{A} \Delta t + \frac{(\mathbf{A} \Delta t)^2}{2} + \ldots \right) \mathbf{x}_k + \left( \mathbf{B} \Delta t + \mathbf{A} \mathbf{B} \frac{(\Delta t)^2}{2} + \ldots \right) \mathbf{u}_k + \mathbf{c}xk+1​=(I+AΔt+2(AΔt)2​+…)xk​+(BΔt+AB2(Δt)2​+…)uk​+c

행렬 지수 형식:

Φ(Δt)=eAΔt,Γ(Δt)=∫0ΔteAτdτ B\Phi(\Delta t) = e^{\mathbf{A} \Delta t}, \quad \Gamma(\Delta t) = \int_0^{\Delta t} e^{\mathbf{A} \tau} d\tau \, \mathbf{B}Φ(Δt)=eAΔt,Γ(Δt)=∫0Δt​eAτdτB

결과:

xk+1=Φxk+Γuk+cΔt\mathbf{x}_{k+1} = \Phi \mathbf{x}_k + \Gamma \mathbf{u}_k + \mathbf{c} \Delta txk+1​=Φxk​+Γuk​+cΔt

발 기구학과 야코비안​

발은 몸 프레임의 위치에 있습니다 (로봇 기하학에서):

ri,body=[xi,yi,zi]⊤\mathbf{r}_{i,\text{body}} = [x_i, y_i, z_i]^\topri,body​=[xi​,yi​,zi​]⊤

월드프레임 위치:

ri(Θ,p)=p+R(Θ)ri,body\mathbf{r}_i(\Theta, \mathbf{p}) = \mathbf{p} + \mathbf{R}(\Theta) \mathbf{r}_{i,\text{body}}ri​(Θ,p)=p+R(Θ)ri,body​

여기서 R(Θ)\mathbf{R}(\Theta)R(Θ)는 오일러 각에서의 회전 행렬입니다.

몸 운동을 발 운동으로 맵핑하는 야코비안:

Ji=[∂ri∂ΘI3]\mathbf{J}_i = \begin{bmatrix} \frac{\partial \mathbf{r}_i}{\partial \Theta} & I_3 \\ \end{bmatrix}Ji​=[∂Θ∂ri​​​I3​​]

필요한 이유:

  1. 유상 다리 궤적 추종을 위한 발 속도 계산
  2. 접지 힘을 몸 토크로 맵핑 (전치를 통해)
  3. 기구학 제약 구현

왜 선형화하고 이산화하는가?​

  1. 볼록성: 선형 동역학 + 이차 비용 = 볼록 QP
  2. 안정성: 선형 모델이 있는 유한-수평선 MPC는 온화한 조건에서 증명된 안정성
  3. 계산 속도: 선형 제약이 있는 응축된 QP는 5ms 이내에 풀이
  4. 유효 범위: 트로트(±0.5 m/s, ±5° 피치)에서 선형화 오류는 10% 미만

선형화 없으면 비선형 최적화 필요 (훨씬 느리고 수렴 보장 없음).
